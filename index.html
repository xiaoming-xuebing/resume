Featurette 01 / 05

传统选品，困在「时效」与「数据」之间

The Brief · 项目背景

跨境电商中小商家高度依赖人工经验选品，面对平台上海量商品数据，分析周期长、反应慢，难以抓住季节性与趋势性机会。
知虾希望用 AI 重塑选品流程：让大模型理解商家意图，自动完成数据检索、品类分析与商品推荐，输出可直接用于决策的选品报告。
我作为 AI 产品经理实习生，参与从竞品调研、Agent 链路设计到模型评测与微调的完整产品周期。

Featurette 02 / 05

一支 Agent 团队，一套工作流

Architecture · 体系架构

基于竞品调研结论，提出 「Multi-Agent + Workflow」混合架构：Workflow 保证确定性的数据处理流程，Multi-Agent 负责意图理解、任务规划与综合研判。
将商家 Query 划分为三类：深耕拓品（已有品类下找新品）、赛道规划（跨品类找机会）、模糊意图（宽泛探索）。
搭建多销铺货、长期稳定、季节热度等 5 大细分场景的选品 Agent，各自独立调用数据工具并产出结构化报告。

Featurette 03 / 05

从 0 到 1，给 Agent 出一张考卷

Evaluation · 评测体系

没有现成评测标准可参考，我从商家真实选品决策出发，拆解出意图识别、策略可行性、商品推荐质量、报告完整度等维度，构建完整模型评价体系。
通过 3 轮评测定位三大核心痛点：意图识别不准、落地执行策略不足、商品推荐不佳，并确定 Agent 改进方向。
评测结论直接驱动迭代排期，形成 「评测 → 定位 → 优化 → 复测」的闭环。

Featurette 04 / 05

3000+ 条数据，把模型调向业务

Fine-tuning · 微调优化

针对意图识别、场景分类、商品推荐不佳的问题，构建 3000+ 场景分类微调数据集，覆盖三类 Query 与 5 大细分场景。
基于火山引擎云平台完成多轮微调，并配合 Prompt 工程同步优化 Agent 表现。
意图识别准确率 81% → 92%（+11pt），商品推荐质量 80% → 95%（+15pt）。

Featurette 05 / 05

数据，是产品最好的影评

Impact · 业务成果

商家实测中，AI 智能选品报告采纳率提升 30%。
平均帮助每家企业降低 40% 人力成本；AI 满意度 ≥ 75%，差评占比 < 25%。

沉淀的评测体系与微调数据集，成为团队后续 Agent 迭代可复用的资产。
